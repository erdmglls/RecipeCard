# 🍽️ RecipeCard | Fine-Dining Web Application

RecipeCard, modern web teknolojileri kullanılarak tasarlanmış, şık ve interaktif bir fine-dining restoran menüsü ve tarif yönetim web arayüzüdür.

## ✨ Özellikler
- Dinamik İçerik & Filtreleme: Vanilla JavaScript DOM manipülasyonu ile kategorilere göre anlık menü filtreleme.
- Yönetim Paneli (Admin): Menü ve tarif içeriklerinin yönetilebilmesi için tasarlanmış admin modülü.
- Modern Görsel Tasarım: Özel CSS temaları (`theme.css`, `style.css`) ile modern UI/UX deneyimi.

## 🛠 Kullanılan Teknolojiler
- HTML5: Semantik yapılandırma
- CSS3: Özel tipografi, grid ve tema stilleri
- JavaScript (ES6+): Dinamik veri listeleme ve etkileşim mantığı
